## 🔧 버그 수정 및 개선 (2026-10-01, v2)

### 치명적 버그 수정
- [x] **단일 저장 + 모자이크 스타일 시 마스킹 미적용 버그 수정** — `drawPixelMaskOnCanvas`가 존재하지 않는 `state.naturalW/H`를 참조해 너비·높이가 `NaN`이 되고, 캔버스 연산이 조용히 무시되어 **마스킹 안 된 원본 얼굴이 다운로드**되던 문제. 미리보기와 저장이 하나의 `drawMasksOnto` → `drawPixelMosaic` 경로로 통합되어 재발 방지.

### 프라이버시 강화
- [x] **서드파티 의존성 완전 제거** — face-api.js, JSZip, AI 모델 가중치, Outfit 폰트를 모두 로컬(`vendor/`, `models/`, `fonts/`)로 번들. 이제 외부 CDN으로 나가는 요청이 전혀 없음 (모델은 로컬 우선, 실패 시에만 CDN 폴백).

### 신규 기능
- [x] **수동 영역 지정 모드** — AI가 못 찾은 얼굴도 사진 위를 드래그해서 직접 가릴 수 있음. "다시 감지" 후에도 수동 영역은 유지됨.
- [x] **블러 / 블랙바 마스크 스타일 추가** — 모자이크 복원 가능성을 우려하는 경우를 위한 강력한 익명화 옵션.

### 안정성·성능
- [x] **파일 검증 추가** — 20MB 초과·빈 파일·비이미지 제외, 최대 50장 제한 (UI 문구와 실제 동작 일치).
- [x] **메모리 개선** — dataURL → Blob URL 전환, 초기화 시 revoke. ZIP 다운로드 후 object URL 해제.
- [x] **iOS 대응** — 저장 이미지 1600만 화소 상한 (초과 시 비율 유지 축소 + 안내 토스트).
- [x] **데드코드 제거** — 미사용 `resizeForDetection`, `state.modelUrl` 삭제. 마스크 렌더링 함수 중복 제거.
- [x] **파일명 처리** — `my.photo.jpg` → `my`가 되던 문제 수정 (`lastIndexOf`), 저장 파일명에 원본 이름 포함.
- [x] **Docker** — `.dockerignore` 추가 (`.git` 히스토리 노출 차단), gzip + 정적 에셋 장기 캐시 nginx 설정.
- [x] **XSS 하드닝** — 파일명·토스트 메시지에 HTML 이스케이프 적용.
- [x] **EXIF 방향** — `image-orientation: from-image` 지정.
